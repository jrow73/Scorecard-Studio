# Scorecard Studio Documentation

This directory separates current cross-version application references from version-specific history.

## Current application references

- `AI.md` — project overview, implementation context, and current release status.
- `FIELD_REGISTRY.md` — established field-registry contract and history.
- `GAME_PACK_FIELD_MATRIX.md` — source and field-availability matrix.
- `PREGAME_DATA_INVENTORY.md` — pregame data-source inventory and adopted source rules.

## Version history

- `v0.2/` — v0.2.0 release record and Designer-completion inventory.
  - `v0.2/builds/` — Build 009–032 implementation, test, release-prep, and RC records.
- `v0.3/` — v0.3.0 architecture, source-evidence, compatibility, release, installation, and package records.
  - `v0.3/builds/` — cumulative Builds 001–005 plus build plans and closure records.
- `v0.4/` — v0.4.0 contracts, audits, release notes, installation, and package records.
  - `v0.4/builds/` — cumulative Builds 001–004, checkpoints, acceptance, and closure records.

Historical filenames are retained inside their version folders so their original build identity remains recognizable. Cross-references were updated when the canonical v0.4.0 repository archive introduced this structure.
