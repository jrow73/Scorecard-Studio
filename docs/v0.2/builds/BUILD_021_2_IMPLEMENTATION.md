# Build 021.2 Implementation

Build 021.2 is a visual-only multi-selection refinement.

## Change

- Multi-selected Designer objects now use a purple halo instead of the normal placement blue.
- Normal placed objects remain blue.
- Single-object selection remains yellow.
- The lasso rectangle remains blue so the temporary drag-selection gesture is visually distinct from the resulting selected objects.

No selection, formatting, movement, alignment, delete, lasso, or Undo/Redo behavior changed.
