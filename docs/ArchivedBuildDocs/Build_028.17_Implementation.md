# Build 028.17 - Inspector Action Polish

## Scope
This decimal build is intentionally limited to two related Designer Inspector polish items.

1. Standardize secondary/destructive Inspector action buttons on the compact Selected Object button treatment. Primary workflow buttons remain large.
2. In Repeated Layout Edit Layout mode, move **Change Placement** into the layout-action area above the divider, with **Create New Item** remaining below the divider.

## Acceptance
- Restore Defaults, Change Placement, Insert Field, Create New Item, Remove Item, and similar secondary/destructive Inspector actions use the compact button language.
- Large primary workflow actions such as Place Field / Place Item on Scorecard are unchanged.
- Editing an existing Repeated Layout shows Change Placement above the section divider and Create New Item below it.
- Change Placement remains hidden outside an established Repeated Layout geometry/editing context.
