Getting Started

Your scorecard. Game ready.

Scorecard Studio fills your own blank baseball scorecard PDF with game-day information. Choose a game, create a reusable layout, place the fields you want, and generate a printable scorecard. Once you have designed your scorecard layout, generating a printable scorecard for your favorite team is just one click per game.

Your work stays in this browser.

No account is required (or possible). Layouts and PDF files are stored locally in the browser's app database, while schedules, lineups, statistics, and other baseball data are requested from the MLB Stats API.

Because there is no Scorecard Studio servers or cloud sync, download a complete backup before clearing your browser data or importing to another device.

Home

Find and Select a Game

Home loads the current schedule for your saved favorite team. Change the date or competition level to browse other games, and use Find a Game to filter the day's schedule.

  • Refresh Schedule requests the latest schedule details, including newly posted lineups and probable pitchers.
  • Select a matchup before opening Game Day or generating a scorecard.
  • The readiness badge describes whether lineups are complete; it does not block research.

Research Companion

Game Day

Game Day is a pregame research view for the selected matchup. It remains spoiler-free when viewing historical games. Compact shows quick orientation, Standard adds traditional pregame detail, and Advanced adds deeper team, player, staff, and standings context. The Game Day screen can also be used for all the inforamtion needed to hand-fill any scorecardd.

  • Refresh retrieves the latest information for the selected game. Use this if lineups or other information may have changed.
  • Switch between viewing Postseason and Regular Season, or MiLB split-season, team and player stats.
  • For Game 2 of a doubleheader, some stats cannot be verified between Game 1 and Game 2, so will be displayed as of pre-Game 1. Things such as games back or wildcard standings require the completion of other ongoing games, not available at Game 2 pre-game.

Layout Library

Create and Manage Layouts

A layout combines one blank scorecard PDF with saved field placements and formatting. New layouts begin with Standard Fields; use Layout Settings to add over 200 custom fields later.

  • A layout needs a name and a valid PDF (which you supply). Names are limited to 80 characters.
  • Layout Settings controls details, the Field Palette, default formatting, and replacement PDFs.
  • Duplicate a layout before experimenting with a substantially different design.
  • A replacement PDF must keep the same page count so existing placements remain meaningful.

Layout Designer

Designer Overview

The Designer lets you place game information onto your scorecard PDF. Select an item from the Field Palette on the left, configure it in the Inspector on the right, and place it on the page. After placement, you can adjust its position, formatting, and other settings at any time.

  • All items in the Designer use fictitious teams, places, and player names. Actual MLB game information will be used when generating scorecards.
  • Any field placed with the designer, which has no pre-game data, will simply be ignored in the final scorecard. Example: you can place all 6 umpires slots, but if only 4 are assigned to the game (MLB Regular Season), they will not appear in the final scorecard. Generating an MLB Post Season scorecard will display all 6 umpires.
  • Text Templates allow you to combine your own free text and data fields; start with a Text Template, or select Text Template when configuring an item. Example: make your own labels, or place a "F" after the temperature.
  • Drag and drop items to move them, or use keyboard arrows to nudge them slightly.
  • Mouse users can Ctrl/Cmd-click or lasso multiple items. Touch users can turn on Select multiple and draw a lasso. Selecting multiple items allows you to move or configure them simultaneously.
  • Mouse users can use Ctrl/Cmd + mouse wheel to zoom in or out. Touch users can use the Zoom menu item on the toolbar.

Designer tips and tricks:

  • Use Layout Settings > Field Palette to manage what MLB data you want printed on your scorecard. Add or remove data items to keep the Palette menu tidy.
  • Most standard keyboard and mouse shortcuts are available in the Designer.
  • Use Undo/Redo when making adjustments.
  • Use Copy/Paste to duplicate items. Copy a configured Away Lineup and paste it as a Home Lineup to quickly mirror the home and away sides of the scorecard.
  • Customize the date format by using the M, D, Y placeholders as follows:
    • Month: M for 1 or 2 month digits (1, 10), MM for double digits with leading zero if needed (01, 10), MMM for abbreviated month name, MMMM for full month name
    • Day: D for 1 or 2 day digits (1, 10), DD for double digits with leading zero if needed (01, 10)
    • Year: YY for 2-digit year, YYYY for 4-digit year
    • Use standard date punctuations of - , / as desired
  • Generate a Test PDF to verify the final appearance and placement of your fields. The generated PDF may differ slightly from the Designer preview and represents what an actual live-data scorecard will look like.

Designer Help

Player Records and Repeating Rows

A repeated object uses the same fields and formatting for every player or record. Configure one position, and the Designer repeats its items throughout the object. A Record Layout, such as Starting Pitcher, contains one record.

  1. Select the object in the Field Palette. For a repeated layout, choose a vertical list, horizontal list, or grid, then set the number of positions. Allow enough positions for the players you want printed.
    NOTE: If you place more positions than available data, the extra positions will be ignored. If you place less positions than available data, the remaining positions will be ignored. Example: If you place 4 Bench positions, but there are 5 Bench players, only the first 4 will be printed.
  2. Select Set Placement and follow the banner above the scorecard. For a vertical list, click the top and bottom row positions; for a horizontal list, click the leftmost and rightmost positions; for a grid, click the top-left and bottom-right positions. The Designer distributes the positions evenly between those points.
  3. Choose a Field or Text Template, configure it, and select Place Item on Scorecard. Click within the first position. The item repeats in all the other positions. Example: Place a Jersey# field on the first lineup row, and it will repeat in the subsequent rows at the same position.
  4. Select an existing item to edit its formatting or content. Use Create New Item to add another field or template to the same row or grid cell.
  5. Use the parent card's Edit Layout to change the arrangement or capacity, and Change Placement to redefine its placement points. Use New Instance for a separate copy of the object.

Repeated placement needs at least two positions to determine spacing. Grids support up to 30 positions in total. Capacity limits how many records can print; it does not create additional players. Generate a Test PDF to check spacing and long names. Text Fit controls an item's text width; it does not add rows.

Designer Help

Starting Lineup

Choose the Away or Home Starting Lineup to build a repeating player layout. Start with nine positions for a conventional batting order, then add whichever player fields your scorecard has spots for.
TIP: once you have fully configured an away Lineup, use the copy / Paste Home-Away functionality to quickly create the corresponding home Lineup.

  • Place a player name, jersey number, defensive position, and any statistics as separate items, or combine them in a Text Template. Using spearate items will result in each item lining up in its own column on every lineup row. Using a Text Template will put single space gaps between each field, so each row will have different spacing, depedning on the length of the player name, etc.
  • The lineup follows batting order as provided by the MLB API. Sorting is unavailable.
  • Use the player name's Name format option, to select full name, F. Lastname, lastname only, etc. Player's "full names" use their preferred name, as supplied by MLB, whereas "first name" is a player's formal name, when different. Boxscore Name is typically just a player's last name, sometimes with an ititial or other distinguishing factor.
  • Defensive Alignment is a separate individual-placement object. Use it to place player names at specific defensive locations, typcially overlayed on a field diagram.
  • The Designer uses fictional players. A generated game scorecard uses the available pregame lineup; review incomplete-lineup warnings before printing.

Designer Help

Bench

The Bench object repeats your chosen player fields for the selected team's bench. Choose a vertical list, horizontal list, or grid to match the space on your scorecard.
TIP: once you have fully configured an away Bench, use the copy / Paste Home-Away functionality to quickly create the corresponding home Bench.

  • Set enough positions for the number of bench players you want to accommodate. The available players may differ by game. Extra spots in the designer will be ignored
  • Add name, jersey number, position, or statistics in the first position; each item repeats for the other bench players.
  • Use Sort to choose an available field, then select ascending or descending order. Choose Sort: None to retain the order supplied by the MLB API.
  • Use New Instance if you need a second independently configured bench object.

Designer Help

Starting Pitcher

Starting Pitcher describes one player. Use its Record Layout to arrange multiple items for that pitcher on a single row. Within the record, use fields or Text Templates to show the values you need. Place items individually (not the SP Record Layout), such as ERA, WHIP, or Win/Loss record if your scorecard has space for them somewhere other than the same row.

  1. Choose the Away or Home Starting Pitcher in the Field Palette to open its Record Layout controls.
  2. Select Place Record Layout and click its location once, anywhere on the row intended for the SP items. Add fields or templates within that record.
  3. Place the pitcher's name, throwing arm, record, ERA, or other available fields where they belong on your scorecard. Select a name format when configuring the name field or inserting it into a template.

There is no row count or sorting for a single starting-pitcher record. Use New Instance if you want another independently formatted use of the same pitcher. If the game has no announced starter, some generated values may be blank.

Designer Help

Bullpen

The Bullpen object repeats pitcher information in a vertical list, horizontal list, or grid. Configure the pitcher group and filter for each instance.

  • Pitcher group: Core Bullpen uses the bullpen list as provided by MLB (not always provided); Additional Starting Pitchers uses the other starters as provided by MLB (not always provided); Combined Pitchers combines both lists without duplicate players.
    NOTE: When Starter or Reliever roles are not available (common for Minor League games), the system will use all available pitchers (except the listed SP) in the Core Bullpen item.
  • Filter: None keeps all pitchers from that group; LHP or RHP limits it by throwing arm. For separate left- and right-handed lists, create two instances and apply a different filter to each.
  • Sort: select an available field and ascending or descending order, or retain the sorting order provided by MLB with Sort: None.
  • Choose enough positions for the group. Filters can reduce the number of players shown; extra positions on the Designer do not create player records on the printed scorecard.
  • Add fields or Text Templates to the first position, then generate a Test PDF to check names, statistics, and spacing.

Designer Help

Configuring the Standings Table

The Division Standings Table places one or more division groups as a single object. Enable it under Layout Settings > Field Palette if it is missing from the palette.

  1. Choose Division coverage: the away division, home division, both team divisions, or the divisions in one or both leagues. When both teams share a division, that division appears once.
  2. Choose a Stat period. Current game context selects the appropriate available period. Choose an explicit period only when you want that period, regarless of the scorecard you will be printing; If standings are unavailable, that area of the scorecard will remaing blank.
  3. Choose Tables per row to arrange division panels side by side. Each division panel is its own Table, in this context.Table width controls the overall object's width, so more panels per row leaves less width for each division.
  4. Choose Team Name or Team Abbreviation, text size, and Maximum teams per division. A low maximum can omit lower-ranked teams, including the selected team. But choosing a high number, like 10, will not show any blank rows if there are only 5 teams in the division.
  5. Select the columns to print. Team is required. The up and down arrows move a column left or right in the printed table. Use compact preset selects Team, W-L, and GB; it does not change the other sizing options.
  6. Choose whether to show division titles and column headings, and whether to highlight the away and home teams. If you highlight the away and home teams, they will be printed in bold. Select Place Standings Table, then click its top-left location on the scorecard.

To revise a placed table, select it, edit the options, and select Apply Table Options. Drag the table to move it or use its resize handle to adjust width. You cannot adjust height, but chaning font sises will make the table taller or shorter. For tight spaces, try abbreviations, fewer columns, fewer tables per row, or a wider table before reducing text size. Check the right and bottom edges in a Test PDF.

The Designer shows fictional standings. Generated tables use the selected game's available standings and division information.

Designer Help

Text Templates

A Text Template combines any free text you want to display with inserted data fields, all in one item. Use it for a compact player record, a label followed by a value, or a line of related statistics. You can use line breaks within the editor, and the resuling items on the scorecard will reflect those breaks.

  1. Choose Text Template for the object or item you are configuring.
  2. Type your fixed text in the editor. Choose a data field, choose a name format if offered, and select Insert into editor. Use the insertion controls to create valid field tokens.
  3. Check the preview box, choose alignment, and place the item on the scorecard.
  4. To revise a placed template, select it and edit its content in the Inspector. Use Text Fit when you need to constrain its width.

Within a repeated object, each inserted field resolves for that position's player. Templates share formatting within a single item; use separate items when values need different formatting or independent placement.
NOTE: If all inserted data fields are missing game data, the entire Text Tempalte field will be ignored. However, if some fields are available, and others aren't, they can leave inserted values blank, while fixed labels and punctuation will remain.

Example: The game's weather summary shows all Temperature, sky conditions, and winds all on one line. You can use the Text Template to create a compact display of this information by inserting just the temperature and conditions items individually on one line, pressing enter, and inserting the wind field on the next line. You can even add your own label, such as "Winds:" prior to the MLB API Wind data for that game.

Layout Designer

Layout Settings

Layout Settings lets you manage each layout's PDF, available data fields, and default formatting.

  • Layout Details - control the name of the layout, its description, and its PDF file.
  • Field Palette - choose which fields are available in the Designer palette. Over 200 MLB data fields are available, with more than 60 selected by default.
  • Default Formatting Options - Lineups, Team Information, and Game Day Information can each have individual default formats, with optional conditional formatting for batter and pitcher handedness. Each item can also be formatted individually after placement.

Live PDF

Generate a Scorecard

After selecting a game, choose a saved layout and select Generate Scorecard. The PDF uses the current game identity, lineup, venue, officials, and other mapped data.

  • If mapped lineup fields are incomplete, review the warning before choosing Cancel or Generate Anyway.
  • For supported postseason or MiLB split contexts, PDF Stats chooses the statistical period used by mapped team and player fields.
  • If a requested statistical source is unavailable, Generate Anyway leaves affected values blank instead of mixing periods.
  • Generated filenames use the game date, team abbreviations, and a safe version of the layout name.

Settings

Settings, Backups, and Local Data

Settings controls your favorite team and appearance. Backup & Restore is the supported way to protect or move layouts and settings to other devices.

  • A complete backup includes all app settings, layouts, and PDF templates. A single-layout backup includes only the chosen layout and its PDF.
  • Share individual layouts with others by downloading a single layout.
  • Import layouts others have shared with you by importing their backup.

Reset Local Data permanently deletes all layouts and settings on this browser. If you previously downloaded a complete or individual-layout backup, you can import it to restore the saved information.

Reference

Troubleshooting and Limits

  • If newly posted game information is missing, use Game Day Refresh or Refresh Schedule and try again.
  • Some values remain blank when the MLB Stats API has not returned them. Scorecard Studio avoids inventing unavailable data.
  • If layouts disappear after browser data is cleared, restore a previously downloaded backup.
  • Scorecard Studio does not provide cloud sync, user accounts, or live-score tracking.
  • Use a current desktop or iPad browser. If the interface becomes stale after an update, perform a normal browser reload.
